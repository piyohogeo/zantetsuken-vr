# Bow-Tie Vertex Split — Blender 4.5 LTS

## v1.23.0：キャップ後の折り返しを比較する3-Face分割（最新版）

`Mesh Repair > 3-Face Sheet Split` に独立コマンド
`Split 3-Face Sheets - Selected / Active` を追加しました。Object Modeで使用します。
ちょうど3面が共有する辺を、逆方向に走査する2面の組と残り1面に分けます。
頂点・辺を同じ位置に複製して接続を分離し、既存面は削除しません。

候補を作業コピー上で実際にOptimized Capし、元の3面共有辺からできた両側の継ぎ目について、
隣接三角形の幾何法線の角度を測ります。0°は滑らかな接続、180°は折り返しです。
評価にはメッシュのローカル座標を使用します。
**継ぎ目の最大角度が最小になる一意な候補**を選びます。面積や角度の合計による同点決着はしません。
仮キャップはTotal AreaのみON、Repair Coincident / Allow Opposite 4-Face Edges /
Cap Isolated Single FacesをONに固定し、パネルの現在の設定には依存しません。

- **適用するのは分割のみ**です。仮キャップの面は保存しません。その後にOptimized Capを実行してください。
- 対象3面共有辺1本につきBoundaryが1本増えます。通常の2面共有辺は切断しません。
- 法線保持のため、対象辺からできる2面共有辺だけをSharpにします。他のSharp設定は保持します。
  頂点位置・ウェイト・UV・一般属性・面とコーナーの対応を確認し、カスタム法線は既存の共通許容値で検証します。
- 全候補を評価し、最小角度から0.0001°以内に複数候補があれば、メッシュを変更せず同点として報告します。
- 探索はメッシュ単位で全組合せ64通りまで。30秒の探索予算を超えた場合も、途中の暫定候補を適用しません。
  時間は各試行の区切りで検査するため、1回の仮キャップ自体が長い場合は30秒を超えることがあります。
- 仮キャップのスキップ・失敗、閉鎖検査の不合格、属性・法線の保持失敗は候補を不採用にします。
  適合候補がない場合やShape Keys / Skin / Multires / Linked・Overrideデータは変更しません。
  仮キャップで頂点融合や元の頂点・コーナーの再対応が必要になる候補も、安全のため不採用です。
  想定外の内部エラーが起きた場合は探索全体を取り消し、残り候補だけから選びません。
- 最大角度は修復対象の継ぎ目に限った評価です。自己交差の除去や造形上の意図の再現を保証するものではありません。

Blender 4.5.13 LTSでProfessionalCharactersの `c_1` / `c_7` / `c_10` を検証しました。
いずれも8組合せ中6候補が検査を通り、最大角度約87.80609°の候補を一意に選択します。
既存面数を維持して頂点・辺を各3個追加し、Boundaryは順に401→404、453→456、403→406です。
その後に上記設定のOptimized Capを実行すると、4-faceも許容しない厳密なNon-Manifold判定の全項目が0になります。
UVは完全一致、カスタム法線の最大ベクトル誤差は0.000491未満でした。
検証では元ファイルを保存せず、元メッシュと一時データの後始末も確認しています。

## v1.22.0：N-gonの重複回避と法線保持の分割再試行

Preserving Triangulateの既存オプション `Minimize New 4-Face Edges (Best Effort)` を拡張しました。
ONでは四角形に加え、N-gonの分割候補を比較し、新しく生じる重複三角形、4面以上共有になる
対角線、既存の共有数の順に少ない候補を選びます。同等の結果では従来のBlender分割を保ちます。
既存の面を削除する処理ではありません。選択した分割の形状品質は候補間の比較に使います。

カスタム法線の保持検査に失敗した場合は、問題の面と同じ頂点を共有する近傍の面について、
別の分割を作業コピー上で試します。法線差の上限 **0.01** と、それに対応する角度上限は
変更していません。各候補で面・コーナー対応、頂点位置、ウェイト、UV、属性、Sharp設定、
カスタム法線を再検査します。探索で改善できなければ従来の分割も検査し、それも通らない場合は
メッシュ全体の変更を取り消します。OFFの動作は従来どおりです。

- 分割候補探索：最大16頂点の面、最大256候補。8頂点以下は有効な全候補を比較可能です。
- 法線再試行：最大6面を対象に各8候補まで取り出し、単独面または2面の組み合わせを試します。
  従来分割へのフォールバックを含め最大32回です。毎回メッシュを検査するため時間が増える場合があります。
- 単純な投影境界、境界内の対角線、正の面積・巻き順を確認できる候補だけを使います。
  大きな面や不安定な投影は無理に変更しません。非平面N-gonでは分割変更により面の内部形状は変わり得ます。
- この処理はベストエフォートです。4-face辺の完全除去や閉鎖を保証せず、後続のSplit 4-Face Sheetsを代替しません。

Blender 4.5.13 LTSで実ファイルを保存せず検証：

- ProfessionalCharacters `c_9`：6092三角形、法線誤差0.004662以下、全Non-Manifoldカテゴリ0。
- ProfessionalCharacters `c_25`：3912三角形、法線誤差0.001257以下、新規4-face辺0。
  元からのBoundary 94本は残り、それ以外のNon-Manifoldカテゴリは0。
- 両方とも面積0三角形0、法線許容値は引き上げずに成功しています。

## v1.17.0：縮退四角形を1三角形へ簡約するオプション（最新版）

Preserving Triangulateに`Simplify Collapsed Quads`を追加しました。OFFが従来互換の初期値です。
4頂点中、隣接するちょうど1組だけが別インデックスかつ完全同位置で、四角形全体には正の面積が

## v1.16.0：閉じた3面共有辺ループの内部パッチ削除

## v1.15.0：Triangulateの4-face回避（最新版）

Preserving Triangulateに`Minimize New 4-Face Edges (Best Effort)`を追加しました。OFFが従来どおりの初期値です。

ONの場合、幾何的に有効な四角形の2対角線を、(1)既存三角形との完全重複数、
(2)4面以上を共有する対角線になるか、(3)既存の共有面数、の辞書順で比較します。
同点なら従来のBeauty方式を使用します。典型的な表四角形／裏2三角形では、裏面と異なる対角線を選び、
各sheetの内部辺を2面共有に保ちます。

- 四角形だけが最適化対象です。5頂点以上のn-gonは従来のBeauty方式へフォールバックします。
- 四角形が凹形、縮退、ねじれ等で候補対角線を安全と判定できない場合もBeautyへフォールバックします。
- 両対角線が既に多面共有の場合など、4-faceを必ず除去できる機能ではありません。
- 異なるsheetが別の対角線を使うと、空間上で対角線が交差する場合があります。頂点を追加して交差を接続する処理ではありません。

## v1.5.0：4指標を選べる3D最適化キャップ（最新版）

ZIPは **`bow_tie_vertex_split-1.5.0.zip`**。同じ拡張IDの更新版です。従来のHard Cap / Ear Clipとは別に、**Optimized 3D Cap**を追加しました。

### 使い方・比較の手順

1. 穴埋め前のメッシュを用意し、バックアップを保存します。
2. オブジェクトモードで `N → Mesh Repair → Optimized 3D Cap` を開きます。
3. 下記4指標をチェックボックスで選びます。まず1つだけONにすると傾向を比較しやすくなります。
4. **Optimize Cap - Selected**（選択メッシュ）または **Optimize Cap - Active**（アクティブメッシュ）を実行します。
5. 見た目を確認したら **Ctrl+Z → 指標を変更 → 再実行**。直前の操作ならF9でも指標を変更できます。すでに塞いだメッシュに単に再実行しても、同じ場所の再最適化はしません。

| チェックボックス | 最小化するもの | 典型的な傾向・注意 |
| --- | --- | --- |
| Total Area | 三角形の総面積 | 張り出した大きな膜を抑える。細長さは保証しない |
| Diagonal Length | 新しい内部対角線の総延長 | 近い頂点を結びやすい。細い三角形が増える場合がある |
| Triangle Slenderness | 三角形の細長さ | 正三角形に近い形を好む。面積や折れ方は別問題 |
| Internal Fold Angle | キャップ内部の折れ角の二乗和 | 大きな折れ返りを避ける。長い・細い面を選ぶ場合がある。やや低速 |

初期値はTotal AreaだけON。複数ONなら、下記の無次元化したスコアを**係数1で加算**します。重みスライダーはありません。ただし、無次元化しても4指標の影響力が完全に等しくなるわけではなく、正規化の選択自体に設計上の判断が含まれます。全OFFは処理をキャンセルします。

実行後、サイドバーに処理時間・キャップ数・使用指標・各ループの**全4指標のスコア**を表示します。A=面積、L=辺長、S=細長さ、F=内部折れ角です。値は小さいほどよい評価です。長い一覧は先頭だけ表示し、全件とスキップ理由はシステムコンソールに出力します。比較は同じ入力ループ同士で行ってください。設定と最後の結果はScene単位です。

### 生成する面

n-gonを作らず、**3D境界から直接三角形分割を最適化**します。面の幾何評価に平面投影を使いません。頂点の追加・移動・融合はせず、境界頂点を使って1ループにつき `n−2` 枚の三角形を生成します。**元の外周のみSharp、新しい内部対角線にはSharpを付けず、全キャップ三角形をFlat**にします。Flatなので内部で陰影の折れ目が見える場合があります。

境界を保った三角形のディスク状接続を対象とし、すでに面に使われている辺への重複した対角線や既存三角形の複製は避けます。新規内部辺・外周辺の2面共有と向き、正の面積、既存属性・UV・ウェイト・カスタム法線の保持を検証します。既存の面は三角化しません。未選択のリンク複製には影響しません。

**この最適化モードでは自己交差・別パーツへの食い込みを許容します。** 従来Hard Capの「Allow Self-Intersections (Ear Clip)」チェックとは独立です。交差の修復や衝突回避は目的関数に含みません。UIにも許容する旨を表示します。

### 評価値の定義

境界頂点の平均位置からの最大距離を `R` とし、メッシュローカル座標を平行移動・`R` で正規化します。以下の長さ・面積はこの正規化座標で計算します。元の頂点を実際に移動する処理ではありません。

- A = 三角形面積の総和（元の面積 / R²）
- L = 内部対角線長の平均（総延長 / R / max(1,n−3)）。外周辺は評価に含めません。
- S = 各三角形の `(a²+b²+c²)/(4√3×面積) − 1` の平均。正三角形が0。
- F = 隣接キャップ三角形間の `(角度/π)²` の平均。側面とキャップの外周角度は評価に含めません。

各ループでは三角形数と内部対角線数が一定なので、平均化はその指標単独の最適解を変えません。正規化面積 `1e-12` 以下の退化候補は除外します。

面積・辺長・細長さのみなら区間DP（O(n³)時間）。折れ角を含む場合は境界辺に接する三角形も状態に持つ拡張DP（O(n⁴)時間、O(n³)記憶）です。固定の境界順序、追加頂点なし、許可された対角線・三角形からなるディスク状分割の範囲内で、選択した評価式を最小化します。あらゆる3D曲面を対象とした大域最適化でも、意図した形の保証でもありません。

### 制限

- **1ループ256頂点まで（折れ角ONは80頂点まで）**。超えるループは警告してスキップします。大きなループや折れ角ONでは、処理中UIが待ち状態になる場合があります。
- 分岐、同位置の境界頂点、Wire／3面以上共有の辺が接する境界、向きの不整合などはスキップ。必要に応じて先にWire Cleanup / Split / Weldを実行してください。
- シェイプキー、Skinデータ、Multires、リンク／オーバーライド付きは既存Hard Capと同様にスキップします。
- Object Modeで対象メッシュの全Boundaryを処理します。Edit Modeの選択ループ限定操作には対応しません。意図した開口部も条件に合えば塞ぐため、対象オブジェクトを確認してください。
- 評価対象は元メッシュのローカル座標です。Armatureなどで変形した評価後形状や非一様Object Scaleは評価しません。後段モディファイアは変更しません。
- キャップの材質・仮UV・新規属性の扱いはHard Capと同様です。投影は仮UV作成だけに使用し、分割最適化とは無関係です。


### 対象と安全条件

- Boundary辺（接するfaceが1枚）の連結成分が、分岐のない4辺・4頂点の閉ループであること。
- 対向する頂点の組がちょうど1組だけ、**メッシュローカル座標で完全一致**していること。距離の許容値はありません。
- 各辺の長さが0でないこと。両頂点が同じ既存faceに属していないこと。
- 融合する頂点のPOINT属性とvertex groupウェイトが一致すること。重なる辺のEDGE属性も一致すること。seam / sharp / crease等の不一致は拒否します。選択・非表示フラグの不一致も保守的に拒否する場合があります。
- 作業用コピーで試行し、頂点が1個・辺が2本・Boundary辺が4本だけ減ること。face数・corner数は変えないこと。
- 融合箇所の頂点がmanifoldになり、接する辺のfaceの向きが整合すること。
- 元faceのcorner位置・順序を維持すること。したがって元faceの幾何形状や面積を変更しません。

候補ごとの不適合はその候補だけ拒否し、他の候補は継続します。最終的な属性復元・検証に失敗した場合は、そのメッシュ全体を変更せずにスキップします。元データへの変更は検証成功後のメッシュ差し替えだけです。未選択のリンク複製は変更しません。

### 属性保持と制限

融合にはBMeshを使いますが、POINT / EDGE / FACE / CORNERの元要素IDを追跡して属性を明示復元し、値の一致を検証します。頂点indexは融合後に詰め直されるため、外部のindex参照は更新されません。

- UVはcorner単位で保持するため、融合頂点同士のUVが異なっていても保持可能です。
- ウェイト不一致は平均化せず拒否します。
- カスタム法線は元cornerに対応させて復元し、ベクトル差 `2e-4` 以下を検証します。元々カスタム法線がない場合、自動法線が融合で変わることがあります。
- シェイプキー、Multires、リンク／オーバーライドのメッシュはスキップします。
- **新しいWeld機能ではSkinモディファイア用頂点データもスキップ**します。既存のSplit機能のSkin属性保持は変更ありません。
- 通常の穴、微小だが面積がある穴、5辺以上のループ、分岐した境界、近いだけの頂点、すでに閉じた面は修復しません。
- この処理は局所的な接続・属性の安全性を検証するもので、モデル全体の自己交差や用途上の意図まで保証するものではありません。

Pythonからは `bpy.ops.object.weld_collapsed_boundaries(scope='SELECTED')`、または `scope='ACTIVE'` で呼び出せます。

## 分離の厳密なルール

各頂点 `v` について、incident faceをグラフのノードとします。**`v` を含む同じedgeを共有するface同士**だけを接続し、Union-Findでconnected componentsを求めます。

- componentが1個以下：何もしません。
- componentが複数：最小face indexを含むcomponentに元頂点を残し、残りに同位置の頂点を1個ずつ追加します。
- face cornerのvertex参照と、該当edgeの端点参照を付け替えます。
- face・loop・edgeの数と順序は変えません。元頂点のindexも維持します。新頂点は末尾に追加します。
- 同じedgeのincident facesはすべて接続扱いです。3面以上が共有するedge自体をsplitすることはありません。
- faceのないwire edgeは元頂点に残します。孤立頂点にも手を加えません。
- 距離判定やMerge by Distanceは使いません。同位置でも既にindexが別の頂点は対象外です。
- 再実行しても、すでに分離済みなら追加変更はありません。

計算量は概ねメッシュの頂点・辺・corner数に比例（Union-Findの償却コストを含む）します。Python側の接続表と安全なメッシュコピーを作るため、大規模メッシュでは処理時間・メモリが必要です。

## 保持するデータ

メッシュを丸ごとコピーしてから、頂点追加と参照更新だけを行います。BMeshへの全面変換・再構築はしません。

| データ | 扱い |
| --- | --- |
| 頂点位置 | 元頂点から同値をコピー。移動・溶接なし |
| UV | loopの順序とデータを維持。複数UVレイヤーも保持 |
| カスタム法線 | 処理前のcorner normalベクトルを保存し、同じloop順で再設定 |
| vertex group / ボーンウェイト | 元頂点の全グループ所属とウェイトを新頂点にコピー。再正規化なし |
| POINT属性・頂点カラー | 新頂点へ元の値をコピー。FLOAT_COLORはlinear、BYTE_COLORはsRGBの保存値を使用 |
| EDGE / FACE / CORNER属性 | 要素順を維持して保持。トポロジー参照属性だけは意図的に更新 |
| seam・sharp・material・smooth | メッシュコピーにより維持 |
| Skinモディファイア用頂点データ | radius / use_root / use_looseをコピー |
| オブジェクト変換・親・モディファイア | 元オブジェクトを維持。モディファイアを適用しない |

カスタム法線は内部エンコードによる微小な数値差が生じ得ます。統合テストでは法線ベクトルの差 `2e-4` 未満を確認しています。カスタム法線が元々ない場合は新設せず、Blenderに自動計算を任せるため、分離箇所のシェーディングが変わる可能性があります。

## 安全策と制限

- **シェイプキー付き、Multires付き、ライブラリリンク／オーバーライドの対象は、修復が必要なら警告してスキップ**します。Basisだけのシェイプキーも対象です。シェイプキーの削除やモディファイア適用を自動で行うことはありません。
- 元メッシュを直接変更せず、作業用コピー上で処理・再検査します。そのオブジェクトの処理が失敗した場合、元データを維持します。複数選択時はオブジェクト単位で処理するため、他の成功したオブジェクトは修復済みになります。
- 修復したオブジェクトには専用の新しいメッシュデータを割り当てます。未選択のリンク複製は変わりません。選択したリンク複製同士もそれぞれ独立したデータになります。
- 元のメッシュデータは明示削除しません。他に利用者がなければ未使用データになります。恒久バックアップではないため、復旧用には保存済み `.blend` またはUndoを利用してください。
- データブロックを新しいものに差し替えるため、別の仕組みが元のMesh IDを直接参照している場合、その参照先は自動で差し替わりません。
- 頂点インデックス依存の外部データ、物理シミュレーションのキャッシュ、特殊なモディファイアの内部状態までは更新しません。必要ならキャッシュ再作成・結果確認をしてください。
- 閉じた境界、自己交差、面の反転、重複面、3面以上を共有する辺、wire接続由来のnon-manifold等は修復しません。同一face内に同じ頂点が繰り返されるなど、不正な接続データは安全のため拒否します。
- 画面上の外観・変形結果・用途への適合は実モデルで確認してください。テストは合成メッシュを使用しており、今回の購入モデルそのものは検証していません。

- 仮キャップ・融合・縮退面の除去をループ単位で検査します。既存面やコーナーの消失、Bow-Tie、閉じ残り、不正な辺共有・向き、残存縮退面があれば、そのループ全体を不採用にします。
- 頂点ウェイト・点属性・統合される既存辺の属性が競合する場合もスキップします。選択状態だけは競合判定から除き、残す要素側の状態を使用します。
- 既存面の形状、UV、カスタム法線、属性、ウェイトを保持検査します。頂点番号・辺番号は融合で変わります。キャップはFlat、境界はSharpです。
- 自己交差・面の重なりは引き続き許容します。閉じたことは、交差のない形状を保証しません。

4指標すべてで探索できますが、このオプションの修復対象ループでは評価は**後処理前の仮三角形**に対するものです。
除去予定の縮退三角形のSlendernessと、それに接するFoldの寄与は0と定義します。
したがって、融合後のメッシュに対する厳密なSlenderness/Fold最小化ではありません。
該当ループの表示は `(pre-cleanup)` 付きです。最適候補が安全検査に失敗した場合、別候補の総当たりはせずスキップします。

Total Area / OFF は92 caps・1306 triangles・2 skipped、ON は94 caps・1318 triangles・0 skipped・2頂点融合。
元blendファイルは保存・上書きしていません。
