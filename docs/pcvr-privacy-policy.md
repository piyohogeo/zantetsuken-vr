# WORLD CUTTER PCVR版 プライバシーポリシー

本ポリシーは、WindowsのPCVR通常プレイ版で利用する、任意のプレイ統計について説明します。統計の送信に同意しなくてもゲームを利用できます。

PCVR版 **0.1.1-alpha.1** の公開日から適用します。

## 収集と利用目的

ゲーム内で同意した場合に限り、性能と安定性の改善に使う統計を収集・送信します。未回答、拒否、撤回中は、プレイ統計を収集・送信しません。広告への利用はしません。

## 統計に含まれる項目

| 分類 | 内容 |
| --- | --- |
| アプリとPC環境 | アプリのバージョン・ビルド識別子、実行プラットフォーム、OS、CPU・GPUのモデル名、グラフィックスAPIと機能レベル、GPUドライバーのバージョン |
| XR環境 | 取得できたヘッドセットの機種名、OpenXRランタイムの名前とバージョン、表示周期、片眼の描画解像度、解像度倍率、MSAA |
| シーンと設定 | シーン、プレイモード、描画経路、切断面のデバッグ色の設定、音量、移動速度、旋回量・旋回方式、スティック配置、刀の角度 |
| 性能の集計 | プレイ時間、フレーム数、CPU Main・CPU Render・GPU・XR GPU時間とフレーム間隔のヒストグラム・最大値・取得できなかった回数、計測元、集計条件の切り替わりや集計できなかったフレームの件数 |
| 負荷と失敗の集計 | 切断件数、破片数と回収件数、CPU・GPUバッファの容量・使用量・空き・拡張回数・不足回数、切断や描画などの内部失敗件数 |
| 統計の識別情報 | ランダムに生成したインストールID・セッションID、同じセッションの送信内容を区別する番号、統計形式のバージョン、テスター区分 |

氏名、メールアドレス、ユーザーが付けたPC名、ハードウェア固有ID、頭や手の移動、移動経路、画像は統計に含めません。個々のフレームや操作の履歴は保存しません。インストールIDは同意時に作る乱数です。セッションIDは起動ごとに新しく作ります。

## 送信のタイミングと端末内の記録

アプリがフォーカスを失った時と、ウィンドウを閉じるなど通常の終了時に、集計した統計をHTTPSで送信します。送信先は開発者のCloudflare Workerで、受信した統計をCloudflare R2に保存します。Cloudflareは通信・保存の基盤として利用します。

強制終了やクラッシュの場合は、終了時の送信を保証しません。通信に失敗した場合は、同じ起動中の次の送信機会に再試行します。

同意の選択とインストールIDは、PC内にゲームの設定とともに保存します。同意後の集計の概要、描画API・ドライバー・XR環境、送信の成否は、PC内のPlayerログにも記録します。

## 保存期間と通信基盤のログ

受信した統計は、保存から90日経過すると自動削除の対象になります。実際の削除まで追加の時間がかかる場合があります。[CloudflareのObject lifecycles](https://developers.cloudflare.com/r2/buckets/object-lifecycles/)

通信元のIPアドレスは通信基盤で処理されます。受信処理は短時間の送信制限のためにIPアドレスから作ったハッシュを使い、生のIPアドレスを統計データや制限用の保存先へ保存しません。

Cloudflareの運用ログ機能を有効にしています。呼び出し・エラーや、リクエストのメソッド・URL・応答状態などの通信に関する情報がCloudflareに保存されます。受信Workerのコードでは、リクエスト本文や統計用トークンを意図的にログへ出力しません。Workers Logsの保持期間の上限は最大7日です。[CloudflareのWorkers Logs](https://developers.cloudflare.com/workers/observability/logs/workers-logs/)

## 同意の変更

初回の `Play statistics` 画面で `Agree` または `Don't send` を選べます。左コントローラーのメニューボタンで開くメニューの `Send play statistics` で、いつでも撤回・再同意できます。

撤回後は新たな収集・送信を停止し、PC内の統計用インストールIDを削除します。送信済みの記録は撤回だけでは直ちに削除されず、保存期間に従って削除されます。再同意すると新しいインストールIDを作ります。
