# WORLD CUTTER Android版の利用案内

Androidの非VR版です。縦画面・横画面で、都市や人物をフリックで切断できます。人型キャラクターの切断・欠損表現を含みます。

現在は公開準備中です。配布候補は **0.1.0-alpha.1／versionCode 7** です。

## 対応環境と確認した端末

- Android 12L（API 32）以降
- ARM64・Vulkan対応端末

| 端末 | code 7で確認した範囲 |
|---|---|
| Galaxy S25 Ultra | 縦画面の起動・描画、横画面の操作・メニュー・Slash表示・ホームからの復帰 |
| Pixel 6 Pro | 更新インストール、縦横の操作・切断・破片表示、設定保持、ホームからの復帰 |
| Pixel 7／Mali-G710 | リモート実機で縦画面の描画、フリック後の人物の破片・倒れた木の表示、設定メニューを短時間確認。断面の正しさ・横画面・長時間性能は未確認 |
| Pixel 10／PowerVR | リモート実機で縦画面の描画、フリック後の人物の破片・倒れた木の表示、設定メニューを短時間確認。断面の正しさ・横画面・長時間性能は未確認 |

他の端末の動作は未確認です。描画機能の対応状況に応じて、利用する描画経路を自動で選びます。

## インストールと更新

公開後は、[GitHub Releases](https://github.com/piyohogeo/zantetsuken-vr/releases)の **WORLD CUTTER Android 0.1.0-alpha.1** から `android-github-0.1.0-alpha.1-7.apk` をダウンロードしてください。

1. ダウンロードしたAPKを、ブラウザまたはファイル管理アプリから開きます。
2. Androidが求めた場合は、その提供元からのインストールを許可し、端末の検査・確認画面に従ってインストールします。
3. アプリ一覧からWORLD CUTTERを起動します。

更新も、新しいAPKを同じ手順で開く手動方式です。同じ正式署名の版からは、設定を保持して更新できます。開発用のdebug署名版からは上書きできません。

ReleaseにはAPKのSHA-256、署名証明書の指紋、第三者表記も添付する予定です。

## 遊び方

- **移動・旋回**：左下の半透明の円を上下へ動かすと前後移動、左右へ動かすと旋回します。
- **切断**：操作UI以外の画面を素早くフリックします。フリックした位置と方向に沿って斬撃が飛びます。ジョイスティックと同時に操作できます。
- **視点**：上下の角度は固定です。端末を縦・横にすると表示と操作UIが切り替わります。
- **メニュー**：右上のMenuで開き、Resumeでゲームに戻ります。

## 設定

| 項目 | 内容 |
|---|---|
| Move／Turn | 移動・旋回の速さ |
| FSR 1／3D resolution／Sharpness | アップスケール、3D描画の解像度、シャープネス |
| Joystick position | 左・下からの配置を縦画面と横画面で別々に保存。初期値は左15%・下30% |
| MultiDrawIndirect／DrawIndirectCount | 対応する描画機能の使用を切り替え。非対応の項目はグレー表示 |
| Apply rendering (reset scene) | 描画機能の変更を反映し、シーンを初期状態へ戻す |
| Reset scene | 切断状態を初期化して、シーンを作り直す |

設定は保存されます。Apply renderingとReset sceneでは、その場の切断状態がリセットされます。

## 確認範囲と既知の制限

| 項目 | 旧版での結果 | code 7での範囲 |
|---|---|---|
| 長時間負荷 | graph導入前の回収変更を含む検証用ビルドで、S25縦・Pixel横とも30分の連続操作を完走。容量不足なし | 短時間の基本動作を確認。graph有効版の長時間負荷・熱負荷は未確認 |
| 16KB環境での実行 | code 6で公式エミュレーターとGalaxy A56 5Gの縦画面の起動・切断・中断復帰を確認 | 16KB整列検査に合格。16KB環境での実行は未確認 |

旧版のPixel長時間試験では、操作終了後の最終採取で電池温度44.0℃・熱状態4に達しました。Pixelの熱負荷の余裕や常時60FPSの維持は確認済みではありません。Galaxy A56 5Gの横画面も未確認です。

S25 Ultra、Pixel 6 Pro、Pixel 10で既知の `DexFile.finalize` 警告を記録しています。警告後もゲームの継続を確認していますが、原因は未確定です。Pixel 7とPixel 10では別の `SwappyDisplayManager` による `libgame.so` 探索失敗を記録しましたが、描画と切断後の表示は継続しました。Pixel 7とPixel 10の結果は、それぞれの端末・OS・ドライバーの組み合わせの描画確認です。
